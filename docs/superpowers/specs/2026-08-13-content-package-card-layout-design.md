# 内容包卡片布局设计

## 目标

将内容包管理的表格列表改为更直观的卡片网格，使管理员可以按内容包逐张浏览，同时保留搜索、学段筛选、新建、查看详情和资源跳转能力。

## 页面结构

- 顶部继续展示内容包标题、说明和“新增内容包”按钮。
- 搜索、学段筛选和结果数量保留在标题下方。
- 内容区由表格改为响应式网格：大屏三列、中屏两列、小屏一列。
- 每张卡片依次展示发布状态、名称、代码、来源学科、学段与教材版本、知识点数、题目数和授权机构数。
- 卡片底部提供“进入内容包”按钮，打开现有详情抽屉；知识点数和题目数继续支持跳转到对应资源。
- 列表下方增加机构权限边界提示，说明机构只能使用已授权内容包。

## 视觉规范

- 延续现有后台的绿色主色、白色卡片、浅灰边框和圆角体系。
- 状态使用轻量胶囊标签区分已发布、草稿和已停用。
- 指标按单行键值形式排列，用分隔线增强纵向阅读节奏。
- 卡片悬停仅轻微改变边框和阴影，不加入与业务无关的装饰。

## 行为与边界

- 不修改内容包数据结构、新建向导、详情抽屉或资源跳转逻辑。
- 搜索或筛选无结果时显示明确的空状态，而不是空白网格。
- 长名称允许自然换行，指标数字使用千分位格式。
- 小屏下筛选区和卡片自动纵向排列，按钮保持可点击宽度。

## 验证

- 更新组件测试，确认卡片入口、状态与权限提示存在，且不再渲染表格。
- 运行类型检查、组件测试与生产构建。
- 在桌面和窄屏尺寸下检查三列到单列的响应式变化。
