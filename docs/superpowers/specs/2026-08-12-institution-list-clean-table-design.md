# 机构列表清爽化设计

## 目标

在不减少机构管理核心信息和快捷操作的前提下，降低单行视觉噪音，让客户能按“机构 → 额度 → 授权 → 操作”的顺序快速扫读。

## 信息层级

- 机构：机构名是唯一主信息；编号和地区是浅色辅助信息。
- 状态：正常机构只用名称前绿点表示；已停用机构显示灰色“已停用”标签。
- 负责人：列表只显示姓名，手机号放入机构详情。
- 额度：只显示“剩余 X 点”和一条短进度条；低额度用红色提示，不同时重复展示总额度、剩余数和百分比。
- 授权：只显示“X 内容包 · X 服务包”，删除装饰图标和重复解释。
- 操作：保留“授权”、“入账”和更多三个轻量入口，不使用大面积按钮。

## 布局与样式

- 保留现有五列桌面端表格，不改为卡片。
- 删除机构左侧圆形图标，单行高度由约 76px 收紧至约 56px。
- 主文字使用现有 `#0F172A`，辅助文字使用 `#94A3B8`，品牌绿只用于可操作文字、状态点和健康进度。
- 操作不依赖颜色表意，每个入口保留明确文字标签。
- 已停用行整体弱化，但不使用删除线，避免被误解为数据已删除。

## 交互

- 点击机构名继续打开机构详情。
- “授权”打开机构授权范围弹窗。
- “入账”进入该机构的额度入账流程。
- “更多”继续打开机构详情和低频操作。

## 验收标准

- 一行内不再出现圆形机构图标、联系电话、授权重复说明和额度百分比文字。
- 正常、低额度、已停用三种行状态均可辨识。
- 授权、入账和详情入口仍可用。
- 常见桌面端宽度下不出现操作拥挤或列文字重叠。
