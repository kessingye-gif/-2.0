# 机构内部组织管理设计

## 目标

将机构、教师、班级、学生页面从“重复开户”调整为机构内部运营管理。服务包开通只建立初始主体和服务权益，后续组织归属、权限及运营信息只在机构管理域维护。

## 信息边界

- 机构管理维护机构基础档案、机构管理员、内容/服务授权、额度账本和内部组织架构。
- 组织架构固定为“校区 → 年级组 → 班级”，每个节点归属唯一机构。
- 教师记录由服务开通同步生成；管理页只维护校区、年级组、任课班级、角色权限、额度与服务使用状态。
- 学生记录由服务开通同步生成；管理页只维护校区、年级组、班级、学籍状态、监护关系和学习服务状态。
- 班级管理是组织架构下的师生编排与任课关系入口，不创建独立开户主体。

## 页面调整

- 机构列表保留“授权”“入账”；新增“组织管理”入口，进入机构内的校区、年级组、班级树。
- 机构详情按“基本信息、组织架构、管理员与权限、授权与额度”分区展示。
- 教师与学生页在进入前要求明确机构范围，机构、校区、年级组、班级筛选逐级收窄；隐藏重复开户字段。
- 班级页从组织树进入，展示班主任、任课教师、学生成员和服务覆盖状态。

## 兼容与验证

- 已存在的机构、教师、学生和服务权益 ID 保持不变。
- 服务开通流程仍可创建初始关系，但不在后续管理页再次创建同一主体。
- 覆盖组织树层级、逐级筛选、已有主体同步、班级成员编排和权限范围测试。
