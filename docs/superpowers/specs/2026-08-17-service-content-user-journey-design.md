# 服务、内容与用户使用主线重构

## 目标

将平台总部后台从“管理机构、教师、班级、学生与点数”调整为“小程序的内容与服务运营后台”。一级业务主线统一为：服务产品 → 内容资产 → 用户服务 → 支撑设置。

## 核心业务链

1. 平台维护知识点与精选题库，形成基础内容资产。
2. 平台将知识点和题目组合为可交付的内容包。
3. 平台配置服务包，规定名称、点数消耗、AI 用量、有效天数、可选内容包范围与可选内容包数量。
4. 平台先导入或维护教师、班级等可选归属信息，再导入用户；用户账号和密码必填，机构必填，教师与班级可选。
5. 为单个或批量用户开通、续费服务时，选择服务包，并从其允许范围内选择内容包。
6. 系统直接从用户所属机构的统一账户扣除服务包点数；教师与班级不参与点数流转。
7. 用户在小程序内使用已开通内容；系统记录服务有效期、AI 用量、内容权限和机构点数流水。

## 对象职责

- 知识点与精选题库：平台内容资产的原子数据。
- 内容包：将知识点和精选题库组合成可交付内容。
- 服务包：定义用户能用什么、能选多少、能用多久、包含多少 AI 用量以及开通需要消耗多少点数。
- 用户服务：记录用户当前服务包、已选内容包、有效期、AI 使用情况和服务状态。
- 教师：用户的可选负责人，可导入和维护，不拥有内容、服务包或独立点数账户。
- 班级：可导入和维护的用户分组工具，用于归属、筛选与批量开通，不是独立业务主线。
- 机构：用户必填的数据归属与服务范围边界，同时拥有统一点数账户并承担服务开通扣点。
- 点数：开通和续费服务时使用的结算规则及流水，不作为独立运营主线。

## 目标信息架构

### 服务产品

- 服务包
- 服务开通与续费规则

### 内容资产

- 内容包
- 知识点
- 精选题库

### 用户服务

- 用户服务列表
- 用户导入
- 组织分组（教师、班级导入与维护）
- 单个或批量开通服务
- 续费与变更内容
- 使用情况与权益记录
- 教师和班级作为筛选、归属与批量选择条件

### 支撑设置

- 机构
- 教师与班级基础信息
- 账号与权限
- 系统设置与审计

## 导航调整

- 一级导航不再分别展示“教师管理”“班级管理”“学生管理”。
- 原“学生管理”升级为“用户与使用”，作为用户服务主入口。
- 教师和班级维护入口收纳到“用户与使用”的“组织分组”页签，旧独立路由继续兼容。
- “商品与权益”改为“服务产品”，默认进入服务包。
- “内容管理”改为“内容资产”，其内部顺序为内容包、知识点、精选题库。
- 点数、额度、入账和流水不再占据一级导航，只在服务开通、机构结算与审计场景按需出现。

## 首页调整

平台总部首页优先展示：服务包数量与启用状态、内容包数量、知识点和精选题库规模、内容完整度、服务中用户、待开通/待续费用户、AI 使用情况。机构额度、教师数、班级数与学生档案数不再作为首页第一屏核心指标。

## 页面关系与迁移

- 现有教师、班级、学生数据和路由暂不删除，先调整导航与入口，保证旧链接仍可访问。
- “用户与使用”复用现有学生服务、权益和使用数据，并提供“用户服务、组织分组、批量开通”三个操作页签。
- 教师、班级和用户导入能力继续保留；推荐先导入教师与班级，再导入用户。用户导入时机构必填，教师和班级可留空。
- 开通服务按用户所属机构分组结算：提交前显示各机构应扣点数，余额不足的机构整组不执行，其余机构可继续执行。
- 同一批次中的机构扣点、用户权益创建和点数流水写入必须保持原子性；重复提交通过业务幂等键阻止二次扣点。
- 现有服务包、内容包、知识点、题库数据继续复用，不进行破坏性迁移。
- 现有教师点数余额与转点流水继续保留为历史兼容数据，但不再用于新的服务开通；现有机构点数流水继续保留，并记录服务包、用户和操作人。

## 第一阶段范围

1. 重排平台总部一级导航和分组。
2. 将教师、班级、学生三个一级入口收敛为“用户与使用”主入口及支撑入口。
3. 调整平台首页指标与快捷入口，使服务包和内容资产优先。
4. 保持机构管理员和教师端现有权限与工作台可用。
5. 保留所有旧路由兼容，不删除数据和功能。
6. 在“用户与使用”内收口教师/班级导入、用户导入与批量开通，并将新开通扣点统一切换为所属机构账户。

## 验收标准

- 平台总部一级导航能直接表达“服务产品、内容资产、用户与使用、支撑设置”。
- 教师管理、班级管理和学生管理不再同时作为平台总部一级导航展示。
- 首页第一屏不再以额度、教师、班级和学生档案总数为核心。
- 用户服务页面能够按机构、教师和班级筛选用户，但服务包与用户权益始终是主要信息。
- 用户可通过 Excel 批量导入；教师和班级可维护并用于归属和批量选择。
- 单个和批量开通均直接从用户所属机构统一账户扣除服务包点数，不经过教师账户。
- 批量开通跨机构时能清晰展示各机构扣点结果；单个机构余额不足不影响其他机构成功开通。
- 开通成功后同时生成用户服务权益和机构点数流水，重复提交不会重复扣点或重复开通。
- 点数只在服务包规则、开通/续费确认和流水中出现。
- 原教师、班级、学生及机构链接继续可访问，现有权限检查不失效。
