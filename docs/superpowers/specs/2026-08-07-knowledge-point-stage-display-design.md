# 知识点列表学段展示调整

## 目标

知识点列表中的关联信息统一展示为“学科 / 学段 / 版本”，不再突出初一、初二、初三等具体年级。

## 展示规则

- 表头由“关联学科 / 年级”调整为“关联学科 / 学段 / 版本”。
- 初一、初二、初三统一展示为“初中”。
- 高一、高二、高三统一展示为“高中”。
- 单元格按“学科 · 学段 · 教材版本”的顺序展示，例如“数学 · 初中 · 人教版”。

## 实现范围

- 仅调整知识点列表的展示逻辑和表头文案。
- 保留现有 `grade` 和 `textbook` 数据，不修改其他页面使用的年级信息。
- 使用一个局部转换逻辑将具体年级映射为学段；未知值保持原值，避免信息丢失。

## 验证

- 检查初一、初二、初三数据均显示为“初中”。
- 检查高中年级数据均显示为“高中”。
- 检查表头、学科、学段和版本展示顺序符合要求。
- 运行类型检查和生产构建。
