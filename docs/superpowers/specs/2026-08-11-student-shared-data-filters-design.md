# 学生共享数据与组织筛选设计

## 目标

班级管理、教师管理和学生管理使用同一份学生数据。学生管理提供机构、老师、年级三级联动筛选，帮助总部按真实组织关系查找学生。

## 数据边界

- `App` 中的 `students` 是学生唯一数据源。
- 班级/教师模块新增或导入学生时继续更新 `App.students`。
- 学生管理直接消费同一 `students`，不维护副本，不新增静态学生名单。
- 本次不改变学生数据结构和导入字段。

## 筛选交互

学生花名册工具栏包含：关键词、机构、老师、年级、服务状态。

- 机构选项来自当前学生数据中的机构并去重。
- 选定机构后，老师选项只显示该机构学生对应的老师。
- 选定老师后，年级选项只显示当前机构和老师范围内实际存在的年级。
- 更改机构时清空老师和年级；更改老师时清空年级。
- 所有筛选与关键词、服务状态取交集。
- 列表数量显示当前筛选结果数，并提供“清除筛选”。
- 当前组合无学生时显示明确空状态。

## 验收标准

1. 班级管理新增学生后，学生管理无需刷新数据源即可看到该学生。
2. 学生管理可按机构、老师、年级依次联动筛选。
3. 上级筛选变化会清理失效的下级筛选。
4. 关键词、服务状态和三级组织筛选可组合使用。
5. 空结果、结果数量和清除筛选行为正确。
6. 全量测试、类型检查和生产构建通过。
7. 功能完成后将 `feat/commercial-fulfillment-demo` 合并进 `main`。
