# 知识点导入字段融合设计

## 目标

将新版知识点导入字段融合到现有三级知识点体系中。Excel 使用单列“大纲层级路径”降低维护成本，导入后仍拆分并保存为一级、二级、三级节点。一级和二级仅承担目录作用，教学属性仅属于三级知识点。

## 导入字段

| 字段 | 必填 | 导入与存储规则 |
| --- | --- | --- |
| 知识点 ID | 否 | 由系统生成并保持稳定，不因名称修改而变化；模板中不要求填写 |
| 知识点名称 | 是 | 三级知识点的统一名称，应与路径最后一级名称一致 |
| 学科 | 是 | 三级路径的唯一性范围之一 |
| 学段 | 是 | 小学、初中、高中、大学；三级路径的唯一性范围之一 |
| 适用年级 | 是，可多选 | 保存为年级列表；同一单元格中的多个值使用中文顿号 `、` 分隔 |
| 适用地区 | 是 | 无地区差异时填写“全国” |
| 大纲层级路径 | 是 | 单列填写严格三级路径，导入时拆为一级、二级、三级节点 |
| 知识类型 | 是 | 概念类、规则/公式/定理类、过程/机制/事件类等受控选项 |
| 核心学习内容 | 是 | 保存到三级知识点，供学生学习和 AI 讲解使用 |
| 教学目标 | 是 | 保存到三级知识点，描述学习后的理解、解释或完成能力 |
| 教学建议 | 是 | 保存到三级知识点，供 AI 讲解或教师教学使用，不直接决定掌握状态 |
| 最小应用验证题 | 是，至少一道 | 填写现有题库题目 ID，多个 ID 使用中文顿号 `、` 分隔；只建立关系，不创建或复制题目 |
| 关联题目 | 是 | 填写现有题库题目 ID，多个 ID 使用中文顿号 `、` 分隔；只建立关系，不创建或复制题目 |
| 验证通过标准 | 是 | 保存到三级知识点，明确达到“已学习”的判定条件 |
| 前置知识点 | 否 | 填写一个或多个完整大纲路径，多个路径使用中文分号 `；` 分隔；可引用数据库已有知识点或本批次知识点 |

## 路径规则与三级存储

- Excel 只维护一列“大纲层级路径”，不再要求分别填写一级、二级、三级列。
- 路径必须严格包含三级，例如“数与代数—方程—一元一次方程”。
- 导入器将路径依次拆为一级目录、二级目录和三级教学知识点。
- 系统内部继续保留三个层级以及父子关系，现有三级树、三级列表和题目关联方式不变。
- 一级、二级节点只保存目录所需的标识、名称、层级、学科、学段和父子关系，不承载教学属性。
- 三级节点保存全部教学属性与关联关系。
- “知识点名称”必须等于路径最后一级；不一致时不自动猜测，以行级错误提示用户修正。
- 完整路径在“学科 + 学段”范围内唯一。相同路径再次导入时匹配已有三级知识点，不重复创建。

路径分隔符由模板统一规定为中文破折连接符 `—`。解析时去除每一级首尾空格，但不自动合并空层级或多余层级。

## 数据模型

现有 `KnowledgePointNode` 保留 `id`、`code`、`name`、`level`、`subject`、`parentId`、题目数量和状态等字段，并做以下调整：

- 增加 `stage`，明确保存学段。
- 将单值 `grade` 兼容升级为多值 `applicableGrades`；旧数据仍可从 `grade` 映射读取。
- 保留 `textbook` 作为历史兼容字段，但新版知识点模板不要求填写教材版本。
- 增加 `applicableRegion`、`knowledgeType`、`coreContent`、`learningObjective`、`teachingSuggestion` 和 `validationCriteria`。
- 增加 `prerequisiteKnowledgePointIds`，最终保存三级知识点 ID，而不是路径文本。
- 增加 `relatedQuestionIds` 和 `minimumValidationQuestionIds`，均引用现有题库记录。

路径文本只作为导入引用和展示辅助。内部关系一律保存稳定 ID，避免知识点改名后关联失效。

## 两阶段导入流程

### 第一阶段：解析、校验与创建知识点

1. 读取表头并映射新版字段。
2. 校验必填字段、受控选项、适用年级和严格三级路径。
3. 校验知识点名称与路径末级一致。
4. 按“学科 + 学段 + 完整路径”查找已有节点。
5. 复用已有一级、二级目录；缺失时创建。
6. 创建或更新三级知识点的教学属性。
7. 建立本批次“完整路径 → 三级知识点 ID”索引。

### 第二阶段：解析关联关系

1. 按完整路径解析前置知识点，先查本批次索引，再查数据库已有知识点。
2. 按题目 ID 解析关联题目和最小应用验证题。
3. 校验所有题目均已存在，不创建新题。
4. 校验最小应用验证题至少一题，且全部属于该知识点的关联题目集合。
5. 将前置路径转换为三级知识点 ID，将题目 ID 写入对应关系。

采用两阶段处理后，同一批次中的前置知识点可以位于引用它的知识点之前或之后，导入结果不受 Excel 行顺序影响。

## 校验与错误处理

- 文件级校验：缺少必需表头、存在重复表头或无法解析文件时停止导入。
- 行级校验：缺少必填值、路径不是三级、名称与末级不一致、受控值非法时标记该行错误。
- 关系校验：前置路径无法匹配、题目 ID 不存在、最小验证题不属于关联题目时标记该行错误。
- 冲突校验：同一“学科 + 学段 + 路径”在同一文件中出现多次但教学属性不一致时，视为冲突，不采用最后一行静默覆盖。
- 环路校验：前置知识点不能引用自身；批次内形成直接或间接循环依赖时拒绝相关行。
- 导入前展示预检结果，包括新增目录数、新增三级知识点数、更新数、关系数和错误明细。
- 存在错误时不提交任何数据，确保知识点、前置关系和题目关系整体一致；用户修正后重新导入。

## 页面融合

### 批量导入弹窗

- 将旧的“一级编码及名称 / 二级编码及名称 / 三级编码及名称”模板说明替换为新版字段说明。
- 明确展示“大纲层级路径一列导入、后台拆分三级”的规则与示例。
- 增加关联题目、最小验证题和前置知识点的填写说明。
- 上传后先进入预检视图，确认无误后再执行导入。

### 知识点列表与树

- 继续显示一级、二级、三级结构，不改变现有导航习惯。
- 表格保留一级、二级、三级三列，呈现路径拆分后的结果。
- 三级知识点行显示学科、学段、适用年级、地区、知识类型和状态等摘要。

### 三级知识点详情

- 展示核心学习内容、教学目标、教学建议和验证通过标准。
- 展示前置知识点，并允许跳转到对应三级知识点。
- 区分“全部关联题目”和“最小应用验证题”；最小验证题使用醒目标记，但仍来自同一题库。

## 兼容策略

- 现有三级知识点和题库外键关系保持不变。
- 旧 `grade` 数据读取时转换为单项 `applicableGrades`，避免历史记录丢失。
- 现有教材版本字段继续保留和展示，避免影响已有页面；新版模板暂不新增非需求字段。
- 原有单表“知识点 + 试题”导入流程保持独立，不在本次改造中改变其创建题目行为。
- 新版知识点导入只允许引用题库已有题目，绝不创建额外题目。

## 验证范围

- 路径解析：合法三级路径可稳定拆分；少级、多级、空级均被拒绝。
- 去重：相同学科、学段和路径复用已有节点；不同学科或学段互不串联。
- 批次前置关系：可关联本批次较早或较晚出现的知识点。
- 已有前置关系：可关联数据库中已存在的三级知识点。
- 题目关系：不存在的题目 ID 被拒绝；最小验证题必须是关联题目的子集且至少一题。
- 冲突与环路：重复冲突、自引用和循环前置关系均能明确报错。
- 原子性：任何行有错误时不产生部分知识点或孤立关系。
- 兼容性：旧知识点列表、三级树、题目关联和学段展示继续正常工作。
- 工程验证：运行单元测试、类型检查和生产构建。
